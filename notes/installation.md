# LeRobot + SmolVLA 安装实战记录

> 基于 AutoDL RTX 4090 + Ubuntu 22.04 + CUDA 12.8 + Python 3.12 的踩坑总结。
> 直接照这个流程走，**避开所有我踩过的坑**。

---

## ✅ 最优安装路径（经验证可跑通）

### 关键决策
- **租 AutoDL 实例时**：选 **PyTorch 2.8 / CUDA 12.8 / Python 3.12** 镜像
- **驱动版本**：要求 NVIDIA Driver ≥ 580（CUDA 12.8 兼容）
- **Python 版本**：必须 ≥ 3.12（LeRobot main 分支强制要求）

### Step 1: 配置 HuggingFace 镜像（国内必做）

    echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
    echo 'export HF_HOME=/root/autodl-tmp/hf_cache' >> ~/.bashrc
    source ~/.bashrc
    mkdir -p /root/autodl-tmp/hf_cache

### Step 2: 配置 pip 镜像

    pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

### Step 3: 装 PyTorch 2.8 + CUDA 12.8

    pip install torch==2.8.0 torchvision==0.23.0 torchaudio==2.8.0 \
      --index-url https://mirrors.tuna.tsinghua.edu.cn/pytorch-wheels/cu128 \
      --extra-index-url https://pypi.tuna.tsinghua.edu.cn/simple

### Step 4: 焊死 torch 版本（防止 lerobot 偷偷升级）

    cat > /root/autodl-tmp/vla/constraints.txt << 'CONSTR'
    torch==2.8.0
    torchvision==0.23.0
    torchaudio==2.8.0
    CONSTR
    pip config set global.constraint /root/autodl-tmp/vla/constraints.txt

### Step 5: 克隆 LeRobot（开学术加速 + 浅克隆）

    source /etc/network_turbo
    cd /root/autodl-tmp/vla
    git clone --depth 1 https://github.com/huggingface/lerobot.git

### Step 6: 安装 LeRobot + SmolVLA

    cd lerobot
    pip install -e ".[smolvla]"

### Step 7: 验证

    python -c "
    import torch
    print('Torch:', torch.__version__)
    print('CUDA:', torch.cuda.is_available())
    from lerobot.policies.smolvla.modeling_smolvla import SmolVLAPolicy
    print('SmolVLA: OK')
    "

## ⚠️ 踩坑记录（避免重复）

### 坑 1: torch CUDA 版本与驱动不匹配

**症状**: `RuntimeError: The NVIDIA driver on your system is too old (found version 12040)`

**根因**: 镜像自带 PyTorch 是 cu130 编译的，但租到的实例驱动只支持 CUDA 12.4。

**解决**: 关机 → 重新租**驱动 ≥ 580 / CUDA 12.8** 的实例。这不是改 PyTorch 版本能解决的。

---

### 坑 2: LeRobot 0.5+ 强制 torch >= 2.7

**症状**:

    ERROR: Cannot install None because these package versions have conflicting dependencies.
    lerobot 0.5.2 depends on torch<2.12.0 and >=2.7
    The user requested (constraint) torch==2.5.1

**根因**: 不能用 torch 2.5 装最新 lerobot，必须 torch 2.7+。

**解决**: 既然要 torch 2.7+，那必须租 CUDA 12.6+ 的实例。

---

### 坑 3: pip 下载 nvidia-cudnn 等运行时极慢（28 KB/s）

**症状**: 装 torch 时卡在 `nvidia_cudnn_cu12-9.1.0.70-py3-none-manylinux2014_x86_64.whl` 几小时不动。

**解决**: 走清华源，不要走 PyTorch 官方源：

    --index-url https://mirrors.tuna.tsinghua.edu.cn/pytorch-wheels/cu128

---

### 坑 4: git clone 慢（108 KB/s）

**症状**:

    Cloning into 'lerobot'...
    Receiving objects: 56% (28214/50245), 127.89 MiB | 108.00 KiB/s

**解决**: AutoDL 学术加速 + 浅克隆双管齐下：

    source /etc/network_turbo
    git clone --depth 1 https://github.com/huggingface/lerobot.git

---

### 坑 5: HuggingFace 登录返回 CloudFront 403

**症状**:

    403 ERROR. Request blocked.
    Generated by cloudfront

**根因**: huggingface.co 主站在国内被 CloudFront 阻断。

**解决**:
- **公开模型（如 SmolVLA）根本不需要登录**，设置 `HF_ENDPOINT=https://hf-mirror.com` 直接下载即可。
- 如果非要登录，先 `source /etc/network_turbo` 走学术加速。

---

### 坑 6: select_action 报 KeyError 'observation.language.tokens'

**症状**: 直接传 `task: ["pick up..."]` 给 select_action 报 KeyError。

**根因**: 字符串需要先经过 preprocess 管线 tokenize，不能直接传 raw 字符串。

**解决**: 用官方 `make_pre_post_processors`：

    from lerobot.policies.factory import make_pre_post_processors
    preprocess, postprocess = make_pre_post_processors(policy.config, model_path)
    processed = preprocess(raw_batch)  # 自动 tokenize
    action = policy.select_action(processed)

---

### 坑 7: conda activate 报 libmambapy QueryFormat 错误

**症状**:

    Error while loading conda entry point: conda-libmamba-solver
    (module 'libmambapy' has no attribute 'QueryFormat')

**解决**:

    conda config --set solver classic

## 🚀 提速三板斧

### 板斧 1: AutoDL 学术加速（最重要！）

    source /etc/network_turbo

对当前终端生效，加速所有 GitHub / 国外 PyPI / HuggingFace 流量。

### 板斧 2: 国内 PyPI 镜像

    pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

### 板斧 3: 大文件用 aria2c 多线程

    apt-get install -y aria2
    aria2c -x 16 -s 16 <URL>

单文件能跑 100MB/s+。
